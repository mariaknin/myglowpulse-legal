# MyGlowPulse — legal pages

Static pages served by GitHub Pages at https://mariaknin.github.io/myglowpulse-legal/

- `privacy/` — politique de confidentialité (fr), `privacy/en/` — privacy policy (en)
- `support/` — page support (fr + en)

Referenced from the app in `lib/privacy.ts` (`PAGES_BASE_URL`) and from the App Store Connect
"Privacy Policy URL" / "Support URL" fields. Keep this repo public: GitHub Pages on a private
repo needs a paid plan.
